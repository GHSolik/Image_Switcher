# Image Switcher

Простая программа на Python, которая позволяет с одного ноутбука менять картинку на другом ноутбуке по нажатию кнопки.

Оба компьютера должны быть в **одной и той же Wi-Fi / локальной сети**.

---

## Как это работает

| Компьютер              | Программа     | Что делает                          |
|------------------------|---------------|-------------------------------------|
| Ноутбук с картинками   | `server.py`   | Показывает изображение и слушает команды |
| Ноутбук с кнопкой      | `client.py`   | Рисует кнопку и отправляет команду  |

При нажатии кнопки клиент отправляет по сети сообщение `"next"`, сервер его получает и переключает картинку на следующую.

---

## Требования

- Python 3.9 или новее
- Библиотека **Pillow** (для работы с картинками)
- Оба ноутбука в одной локальной сети

## Запуск

### На ноутбуке с картинками (сервер)

```bash
python server.py
```

Откроется окно с первой картинкой.  
Сервер начнёт слушать порт **5555**.

**Важно:** узнай IP-адрес этого ноутбука:

- **Windows**: открой командную строку → введи `ipconfig` → ищи строку «IPv4-адрес»
- **Linux / macOS**: введи `ip a` или `ifconfig` → ищи адрес вида `192.168.x.x`

### На ноутбуке с кнопкой (клиент)

```bash
python client.py
```

В поле ввода впиши IP-адрес серверного ноутбука и нажми кнопку **«Сменить картинку»**.

Картинка на втором ноутбуке должна смениться.

## Возможные проблемы

| Проблема                              | Что проверить                                      |
|---------------------------------------|----------------------------------------------------|
| «Сервер не запущен или порт закрыт»   | Запущен ли `server.py`? Правильный ли IP?          |
| «Таймаут»                             | Оба устройства в одной сети? Firewall не блокирует порт 5555? |
| Картинки не появляются                | Есть ли файлы в папке `images/`?                   |
| Windows Firewall                      | При первом запуске Windows может спросить разрешение — нужно разрешить |

## Сборка в .exe (полноценные программы без Python)

Можно превратить обе программы в обычные `.exe` файлы, которые запускаются двойным кликом и не требуют установленного Python.

### 1. Установи PyInstaller

```bash
pip install pyinstaller
```

### 2. Собери сервер

```bash
pyinstaller --noconfirm --onefile --windowed --name "ImageServer" --add-data "images;images" server.py
```

### 3. Собери клиент

```bash
pyinstaller --noconfirm --onefile --windowed --name "ImageClient" client.py
```

Готовые файлы появятся в папке `dist/`:
- `ImageServer.exe`
- `ImageClient.exe`

### Как работать с картинками после сборки

Самый удобный способ — **положить папку `images` рядом с `ImageServer.exe`**.

```
папка/
├── ImageServer.exe
└── images/
    ├── фото1.jpg
    ├── фото2.png
    └── ...
```

Программа сначала ищет картинки именно там.  
Если внешней папки нет — использует те, что были упакованы внутрь `.exe` при сборке.

Менять картинки можно в любой момент, просто заменяя файлы в папке `images` — пересобирать `.exe` не нужно.

> **Примечание:** флаг `--add-data "images;images"` работает на Windows.  
> На Linux/macOS нужно писать `"images:images"`.

## Как выложить на GitHub

Если ты ещё никогда не работал с GitHub — вот пошаговая инструкция.

### 1. Создай аккаунт
Зайди на [github.com](https://github.com) и зарегистрируйся (если ещё нет).

### 2. Создай новый репозиторий
1. Нажми зелёную кнопку **New** (или **+** → New repository)
2. Название: например `image-switcher`
3. Описание (по желанию): `Кнопка на одном ноутбуке меняет картинку на другом`
4. Выбери **Public**
5. **Не** ставь галочки «Add a README» и т.п. (у нас уже всё есть)
6. Нажми **Create repository**

### 3. Загрузи код на GitHub

Открой терминал в папке проекта и выполни команды **по очереди**:

```bash
git init
git add .
git commit -m "Первый коммит: программа смены картинок"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/image-switcher.git
git push -u origin main
```

> Замени `ТВОЙ_ЛОГИН` на свой логин на GitHub.

Если Git попросит логин и пароль — вместо пароля нужно использовать **Personal Access Token**  
(Settings → Developer settings → Personal access tokens).

## Технические детали (для любопытных)

- Связь между компьютерами идёт через **TCP-сокеты**
- Сервер слушает на `0.0.0.0:5555` (доступен из локальной сети)
- Клиент отправляет простую текстовую команду `next`
- Интерфейс сделан на **Tkinter** (встроен в Python)
- Картинки обрабатываются библиотекой **Pillow**
- Сетевой сервер работает в отдельном потоке, поэтому окно не зависает
